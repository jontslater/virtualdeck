# VirtualDeck v1.2.4

## Highlights

- **In-app feedback:** Rate your experience, pick feature ideas, and optionally leave a contact email—without opening an external form.
- **One-time prompt:** After a few days of use, a gentle check-in appears (dismissible with **Remind me later** or **Don't ask again**).
- **Help & Preferences:** **Help → Send feedback / Request a feature…** and **Preferences → Feedback** open the same form any time.
- **Report Bug:** No longer launches an external Google Form; use in-app feedback instead.
- **Modal form controls:** Checkbox and radio alignment in modals (including the feedback form) is fixed for easier reading.

## Upgrade notes

- In-app auto-update from **1.2.3** uses the same GitHub Release artifacts (`latest.yml`, installer, blockmap).
- Feedback is sent to `https://virtualdeck.app/api/feedback` from the main process (no API keys in the client).
