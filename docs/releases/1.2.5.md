# VirtualDeck v1.2.5

## Highlights

- **Theme import:** Imported themes and skins (including Christmas/Cartoon) apply immediately—CSS, injected skin styles, and Twitch chat styling—without reloading the app.
- **Sound playback modes:** Each sound button has a **Playback** setting under the volume slider: **Repeat** (default, same as before—overlap on rapid presses) or **Start/Stop** (press again while playing to stop long clips). Saved with your deck layout and backup/restore.

## Upgrade notes

- In-app auto-update from **1.2.4** uses the same GitHub Release artifacts (`latest.yml`, installer, blockmap).
- Existing decks behave unchanged until you set a button to **Start/Stop**.
