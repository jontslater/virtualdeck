# VirtualDeck v1.2.7

## Highlights

- **Hydration tracker fixes:** The settings panel now opens as a **floating widget** (like other VirtualDeck tools) so it no longer shoves the deck sideways.
- **Live preview:** The in-panel preview shows your gauge at **1920×1080**, matching the OBS browser source.
- **Browser source URL:** Copy a real `http://localhost:…/hydration` URL (no more broken “function” text) with the same **Copy** control as other overlays.
- **Sounds:** **Browse…** picks an audio file via the system dialog and stores it under your `sounds/` folder; you can still type a path manually.
- **Channel point rewards:** The trigger reward dropdown loads your Twitch custom rewards when connected, with clear messages when the list is empty or Twitch needs a refresh.

## Upgrade notes

- In-app auto-update from **1.2.6** uses this release (`latest.yml`, installer, blockmap).
- If the reward dropdown stays empty after updating, **reconnect Twitch** in VirtualDeck so your token includes `channel:read:redemptions` (default for new connections).
