# VirtualDeck v1.2.0

**Target:** Public launch milestone (Nov 2026)

## Highlights

- **Licensing:** Free tier (15 active buttons) and **VirtualDeck Pro** (one-time license, BYOK AI assistant, unlimited buttons).
- **Lemon Squeezy** integration behind config; mock provider for dev.
- **Auto-updater** re-enabled against GitHub Releases (`jontslater/virtualdeck`).
- Input-focus / dialog fixes from `fix/input-focus` branch.

## Upgrade notes

- Decks with more than 15 buttons **keep all data**; slots beyond the first 15 are locked until Pro is activated.
- Updates from **1.1.8** use the existing `latest.yml` + `VirtualDeck-Setup-*` artifact naming.

## Known limitations

- Public CI builds omit Raven staging (AITuber not in Actions); full Raven installers are built on a maintainer Windows machine with `npm run build:win:with-raven`.
