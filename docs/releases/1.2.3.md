# VirtualDeck v1.2.3

## Highlights

- **Christmas (Cartoon) skin:** Festive cartoon theme with snow, candy-cane accents, styled stat cards and sound buttons, plus Twitch chat styling. Skins can style the master volume slider (candy-cane track and thumb on this theme).
- **Master volume:** Dashboard **Master** slider and mute control scale volume for all soundboard button playback (shortcut **M**; double-click the mute button sets the slider to 0%).
- **Deck layout backup & restore:** **Tools → Back up deck layout…** / **Restore deck layout…** (also under **Preferences**) export and import profiles, button order, macros, and bundled userData media in one JSON file.
- **Twitch chat — secret words:** Deck buttons can fire on **whole words anywhere in chat** (case-insensitive), Mix It Up–style, in addition to classic `!command` triggers. Configure per button under chat command settings.

## Upgrade notes

- In-app auto-update from **1.2.2** uses the same GitHub Release artifacts (`latest.yml`, installer, blockmap).
