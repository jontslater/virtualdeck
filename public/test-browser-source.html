OBS Browser Source Setup

  1. Open OBS Studio
  2. Add a new "Browser Source"
  3. Set the URL to: http://localhost:8080/overlay
  4. Set width to: 1920
  5. Set height to: 1080
  6. Check "Shutdown source when not visible"
  7. Check "Refresh browser when scene becomes active"

Instructions

  1. Start the Virtual Deck application
  2. Copy the overlay URL above
