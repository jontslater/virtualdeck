Twitch Placeholders Guide

Use these placeholders in your alert text and chat messages. They will be automatically replaced with real data when triggered.

📺 All Twitch Events

Placeholder Description Example
{username} Twitch username (lowercase) tehchno
{display_name} or {displayName} Display name (proper casing) TehChno

👥 New Follower

{username} Username of new follower coolviewer99

⭐ Subscriber / Resubscriber

{username} Subscriber username loyalfan
{tier} Subscription tier 1000 (Tier 1), 2000 (Tier 2), 3000 (Tier 3)
{months} Cumulative months subscribed 12
{message} Resub message (if provided) Love this stream!

🎁 Gifted Subscription

{username} Username of gift giver generousfan
{tier} Subscription tier gifted 1000, 2000, 3000

🎯 Raid

{username} Username of raider friendlystreamer
{viewers} Number of raiders 250

💎 Bits / Cheer

{username} Username who cheered bitsmaster
{bits} Number of bits cheered 500
{message} Cheer message (if provided) Keep up the great work!

🚫 User Ban

{username} Username who was banned baduser123
{moderator} Moderator who issued the ban modname
{reason} Ban reason (if provided) Spam

✅ Daily Check-In

{username} Username who checked in dailyviewer
{display_name} Display name DailyViewer
{total_checkins} Total times checked in (all time) 42
{streak} Consecutive days checked in 7

🎯 Progression System

{username} Username who redeemed contributor123
{action} Your custom action word watered, built, fed (based on your Action Word setting)
{object} The progression name Building a House
{count} Total redemptions across all stages 15
{stage} Current stage number 2
{total_stages} Total number of stages 5
{required} (Overlay Text only) Redeems required for current stage 10

💡 Usage Examples

Follower Alert: Welcome {username}! Thanks for following!
→ Welcome coolviewer99! Thanks for following!
Subscriber Alert: {username} subscribed for {months} months!
→ loyalfan subscribed for 12 months!
Raid Alert: {username} raided with {viewers} viewers!
→ friendlystreamer raided with 250 viewers!
Daily Check-In: Welcome back {username}! You've checked in {total_checkins} times!
→ Welcome back dailyviewer! You've checked in 42 times!
Progression Chat Message (Action Word: "watered"): {username} {action} the tree! {count} total contributions (Stage {stage}/{total_stages})
→ contributor123 watered the tree! 15 total contributions (Stage 2/5)
Progression Overlay Text: Stage {stage}: {count}/{required}
→ Stage 2: 3/10
💡 Pro Tip: Placeholders are case-sensitive! Use exactly as shown above for them to work properly.

Welcome to VirtualDeck! 🎉

To enable Twitch chat, alerts, and events, you'll need to set up your Twitch credentials.

Quick Setup Guide:
  1. Go to twitchtokengenerator.com
  2. Choose Custom Token and select ALL token permissions
  3. Click Generate Token and log in with Twitch
  4. Copy your ACCESS TOKEN, CLIENT_ID, and TWITCH_USER_NAME
  5. Paste them into the setup form

You can access Twitch Setup anytime from Edit → Preferences → Twitch Integration
